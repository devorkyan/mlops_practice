# Лабораторная работа №5: Автоматизация тестирования ML-моделей

## Общие сведения
Цель данной работы — внедрение механизмов автоматизированного тестирования для проверки качества работы модели машинного обучения. В работе демонстрируется, как с помощью библиотеки `pytest` можно обнаруживать деградацию метрик модели при появлении аномалий (шума) в данных.

## Сценарий работы
1. **Генерация данных**: Создаются три набора «чистых» данных и один набор с искусственно внесенным шумом (выбросами в диапазоне индексов 25–45).
2. **Обучение**: Модель линейной регрессии обучается на первом чистом датасете.
3. **Валидация**: Создается тестовый скрипт, который проверяет сохраненную модель на остальных датасетах.
4. **Результат**: Тесты на чистых данных проходят успешно, а тест на зашумленных данных падает, сигнализируя об обнаруженной проблеме.

## Структура файлов в папке `lab5/`
* `data_1.csv` — обучающая выборка.
* `data_2.csv`, `data_3.csv` — контрольные чистые выборки для тестов.
* `noisy_data.csv` — выборка с аномалиями.
* `linear_model.pkl` — сериализованная обученная модель.
* `test_model.py` — файл с тестами `pytest`.

## Критерии качества (Quality Gates)
В тестах установлены следующие пороговые значения:
* **MSE (Mean Squared Error)**: < 1.5
* **R² (Coefficient of Determination)**: > 0.85

Если модель на предоставленных данных не вписывается в эти рамки, тест считается проваленным.
